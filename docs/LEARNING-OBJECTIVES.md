# Learning objectives

The [workshop learning path](https://codemillmatt.github.io/interview-coach-agent-framework/workshop/) is the canonical curriculum.

By completing it, you should be able to distinguish models from agents, configure a Foundry-backed `ChatClientAgent`, define and inspect tool calls, connect MCP services, reason about persisted records versus conversation context, and build the reference handoff workflow.

The workshop supplies UI and database plumbing and includes recovery checkpoints. See the [architecture reference](ARCHITECTURE.md) for the completed application's components.
