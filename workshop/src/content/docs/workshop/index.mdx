## What you bring

Working knowledge of C#, dependency injection, and basic HTTP applications. Set aside a full day, or work through the modules across several sessions. You can leave and return to the guide; completed lessons are remembered in this browser.

## What we supply

The Blazor UI, service defaults, Aspire project structure, and Cosmos data model/repository. You focus on the agent instructions, tool contracts, MCP connections, state usage, and handoffs. Each lesson names both the code you change and the infrastructure you inherit.

## What you will finish

A local application with the same Foundry-backed single-agent and five-specialist modes as the reference repository. The final download is compared against a pinned reference revision, not a separate look-alike demo.

The agents run in the .NET service. **Using a Foundry model is not the same thing as hosting your agent in Foundry Agent Service.** Cloud deployment and other hosting options are separate extension paths.

## How to work through a lesson

Read the what and why before revealing the solution. Make the change in your own project, predict a result, then use the checkpoint's observations to decide whether it worked. Mark the lesson complete only after that.

If you get stuck, use a hint before the full solution. To catch up, extract a checkpoint into a **new folder**. There are no reset commands that discard your work, no required branch changes, and no quizzes that block your progress.

Keep a short note of the model deployment, package versions, and sample input you used. Generated prose varies; your goal is to explain the behaviour and its evidence, not match a screenshot word for word.
