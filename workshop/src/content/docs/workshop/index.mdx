We'll be using .NET with the Microsoft Agent Framework, Microsoft Foundry, Docker, and more throughout this workshop.

Chapter 0 checks the prerequisites and lets us try the finished app to make sure everything is installed correctly. In Chapter 1, we'll open a separate starter and keep editing it for the rest of the course. Each build chapter ends with a working version and a short check.
<br/>
If you want to jump right in: <a class="action-link" href={siteLink('workshop/00-orientation/')}>Start Chapter 0: Get ready and try the interview coach</a>

## How to be successful

The starter supplies the Blazor chat interface, Aspire helpers, and database repository. We'll write the agent instructions, tool connections, and handoff rules. Every build and Aspire command will be able to be run from your working folder's root.

Each code step specifies a file to edit and shows exactly what to add, replace, or remove. Apply the steps in order and finish the whole edit group before building the application. Some edits depend on the next one to compile. We've included expandable notes for explanations on topics tangential to this course, so you can read more when a detail interests you.

After building the app, try the chapter's input and look for its expected result. Early on, that's a reply to your question. Later, we'll look for a tool invocation, a saved record, or a handoff.

## Keep your place

Mark a chapter complete after trying its check. Completion marks appear in the sidebar and chapter list, and the landing page's continue action takes you to your next unfinished chapter. Your progress is remembered in this browser.

## Get a fresh starting point

We've provided a final working sample at the end of each chapter. Extract one into a new folder and keep your existing work alongside it. Before starting a cloud-backed checkpoint, check which Azure resources that folder may create; separate folders can have separate provisioning contexts.
