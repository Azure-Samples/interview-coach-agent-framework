We'll split intake into two roles. Triage sends the conversation to the receptionist, which collects and saves the interview materials. You'll see that transfer before adding any interviewers.

Continue in the same `interview-coach-lab` project from the previous chapter. Keep `CreateSingleAgent` intact for later comparison. Work in `src/InterviewCoach.Agent/AgentDelegateFactory.cs` and root `apphost.settings.json`.

## Watch intake change hands

From the working project root:

<TabItem label="Bash">

```bash
aspire stop --apphost ./apphost.cs
dotnet build InterviewCoach.slnx
aspire start --apphost ./apphost.cs
```

</TabItem>
<TabItem label="PowerShell">

```powershell
aspire stop --apphost ./apphost.cs
dotnet build InterviewCoach.slnx
aspire start --apphost ./apphost.cs
```

</TabItem>
</Tabs>

Open `coach` in DevUI for a fresh conversation. Supply an exercise ID here because the WebUI normally supplies the session ID:

```text
Use session ID 22222222-2222-4222-8222-222222222222.
Set up an interview with this fictional resume text: "I build C# web APIs."
The job description is "Backend developer." Save these inputs.
```

Inspect the transfer from `triage` to `receptionist` in the run details, then the receptionist's InterviewData calls. Find the same ID in `interviewdb` / `interviewsessions` and check both saved text fields. Use a fresh GUID when repeating this exercise.

At this checkpoint, the receptionist finishes by reporting that the interview specialists are still to come. You've built the first handoff and saved its intake result.
