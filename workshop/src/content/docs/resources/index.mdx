## Checkpoint projects

<p>Download the starter once in <a href={siteLink('workshop/01-starter/')}>Chapter 1</a>, then keep editing the same <code>interview-coach-lab</code> project through the course. The 13 archives below support comparison and recovery. Extract one into a separate folder and compare the relevant files while preserving your work. Checkpoints with code changes have a patch that shows the transition. The debugging lesson and workshop summary use the completed source from Chapter 12.</p>

<p><strong>The starter is cloud-free; later checkpoints reuse the Chapter 0 model.</strong> An extracted recovery folder has its own user-secrets store. Apply the <a href={siteLink('workshop/02-first-coach/#connect-the-model')}>existing-model settings</a> there before starting it. Model calls are billable, and shared cloud resources remain until <a href={siteLink('resources/deployment/#remove-only-the-resources-you-own')}>cleanup</a>.</p>

<p>Downloads are generated from the immutable <code>{labs.sourceTag}</code> tag. They include package pins, required resource reuse, and separate learner configuration. The completed checkpoint keeps the workshop startup helper, MCP discovery probe, and session ID display. It provides the full interview workflow while keeping the file layout used in the lessons. The download manifest records the source revision and generated file hashes.</p>
