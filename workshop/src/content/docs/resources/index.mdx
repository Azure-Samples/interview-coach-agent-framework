## Recover without losing your work

Each archive is a complete project. Extract it into a new folder, copy only your private environment settings where needed, and follow that lesson's observations. The patch shows what changed since the preceding checkpoint.

Direct .NET package versions are pinned in the archives. Application sources are tied to revision `68fd993f`; the final checkpoint differs only in package pins and its workshop information file. The parser image still follows the reference's `latest` tag: record its digest when troubleshooting a later run.
